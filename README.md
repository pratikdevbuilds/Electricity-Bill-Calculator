# Electricity Bill Calculator

A simple Python program to calculate electricity bills using slab-based pricing.

## Features

* Calculates bill based on electricity units consumed.
* Uses different rates for different slabs.
* Beginner-friendly Python project.

## Tariff Rates

* First 100 units → ₹5 per unit
* Next 100 units → ₹7 per unit
* Above 200 units → ₹10 per unit

## Example

Input:
250

Output:
TOTAL AMOUNT = 1700 /-

* Python
